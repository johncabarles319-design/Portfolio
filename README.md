# Hackthon Portfolio

Option 1 is the standalone portfolio experience for presenting work, process, and future-facing projects. It is intentionally independent from the ScamSignal product site in the separate `hackthon-option-2` repository.

## Run locally

```bash
npm ci
npm run dev
```

## Verify and build

```bash
npm test
npm run build
```

The production output is written to `dist/` and can be deployed as a static site on GitHub Pages, Netlify, or any static host.
